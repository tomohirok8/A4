# 株ポートフォリオ

保有株を管理するローカル Web アプリ（Python / Flask + SQLite）。

## 機能

- 銘柄ごとの取得単価・所持数・現在株価・損得額・損得率・配当額・配当利回り（取得単価／現在株価ベース）を表で表示（行の追加・編集・削除）
- 銘柄コードを入力すると銘柄名を自動入力（日本株は日本語名）。銘柄名が空の行は「現在値を取得」で埋める
- 所持数0の銘柄を隠す切り替え
- 買付余力を入力し、総資産（買付余力＋総評価額）を表示
- 「現在値を取得」で株価と為替レートを取得（yfinance、失敗時は Yahoo Finance を直接参照）
- 米国株は円換算。銘柄ごとの損得は円（取得時レートによる為替損益込み）とドルの両方で表示し、合計は円
- 「保存」でその日（日本時間）の株価・評価額・取得額・損得をデータベースに保存（同じ日は上書き）
- 保存データの推移グラフ（総評価額・総取得額・総資産・総損得、銘柄を選んで株価／騰落率）
- 「配当実績」タブ: 実際に受け取った配当を西暦年ごとに入力（配当単価×所持数、税率から手取りを計算。年の切り替え、年別・累積の額面／手取り）
- 銘柄ごとの財務状況のポップアップ（PER・PBR・配当・ROE・自己資本比率・アナリスト評価・年次決算など）
  - 年次決算は設定すると過去5年分（米国株: SEC EDGAR、日本株: EDINET）。未設定時は Yahoo Finance の4年分

## 起動

macOS では `start.command` をダブルクリック。初回は仮想環境の作成とライブラリのインストールを自動で行い、ブラウザで http://127.0.0.1:5050 を開きます。

手動で起動する場合:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

## データ

すべてのデータは `portfolio.db`（SQLite）に保存されます。新しい項目は起動時に既存のデータベースへ列・表を追加する形で反映し、保存済みのデータはそのまま使います（以前の保存分の新しい項目は空欄）。個人データを含むため Git の管理対象外です。バックアップはこのファイルをコピーしてください。

## 構成

| ファイル | 内容 |
|---|---|
| `app.py` | Web サーバーと API |
| `db.py` | データベース定義・設定の保存 |
| `prices.py` | 株価・為替レートの取得 |
| `fundamentals.py` | 財務情報の取得（Yahoo Finance） |
| `statements.py` | 過去5年分の年次決算（SEC EDGAR / EDINET） |
| `templates/index.html` | 画面 |

株価・財務データは Yahoo Finance 等の外部データで、遅延・欠損・誤りを含む場合があります。投資判断はご自身で行ってください。
